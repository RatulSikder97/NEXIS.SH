# NEXIS

NEXIS is an autonomous incident recovery platform. When an incident lands,
NEXIS spins up a multi-agent recovery loop — root-cause analysis, fix
synthesis, validation, GitOps PR — and hands back a verified patch in
under a minute.

This site is the operator + developer reference. It assumes you have an
invite code and an account at [app.nexis.dev](https://app.nexis.dev).

## Start here

- **[Install](/install)** — sign up with an invite, connect GitHub, run the
  sample fixture end-to-end.
- **[Integrations](/integrations)** — wire NEXIS into Sentry, GitHub,
  ArgoCD. Each integration ships with a short happy-path checklist.
- **[Agent reference](/agent-reference)** — what each agent owns, what it

- **[Runbook](/runbook)** — the ten failures we've seen most often in beta

- **[Architecture](/architecture)** — port + adapter layout, recovery
